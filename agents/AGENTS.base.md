# AGENTS.base.md

这是项目级 `AGENTS.md` 的基础模板，适用于大多数代码仓库。复制到目标项目根目录后，应结合项目技术栈进行裁剪。

## 项目目标

请先阅读 `README.md`、构建脚本、测试脚本和主要源码目录，理解项目用途后再修改代码。

## 工作规则

1. 优先做最小必要变更，避免无关重构。
2. 修改代码前先确认相关目录结构、依赖管理方式和测试命令。
3. 保持现有代码风格、命名约定和目录组织。
4. 不要引入未经确认的新框架、新中间件或大型依赖。
5. 涉及配置、部署、数据库、权限、鉴权时，必须说明影响范围和回滚方式。
6. 变更完成后，应说明修改点、验证方式和潜在风险。

## 安全约束

- 不要写入真实密钥、密码、证书、Token、Cookie。
- 不要将 `.env`、私钥、生产配置提交到仓库。
- 不要默认执行破坏性操作。
- 需要删除数据、重置环境、强制覆盖时，必须先给出确认点。

## 输出要求

Agent 完成任务后应给出：

1. 修改了哪些文件。
2. 为什么这样改。
3. 如何验证。
4. 是否存在未验证项或风险。
